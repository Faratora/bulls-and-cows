# Bulls and Cows

Игра «Быки и коровы»: компьютер загадывает секретное число из уникальных
цифр, игрок угадывает его, получая после каждой попытки подсказку —

- **бык** — цифра угадана и стоит на своём месте;
- **корова** — цифра есть в числе, но на другом месте.

Реализовано в функциональном стиле: чистые функции, иммутабельные данные,
каррирование, рекурсия и мемоизация. Логика игры не зависит от DOM.

## Возможности

- Настройка раунда: длина числа (2–6) и система счисления
  (bin / oct / dec / hex); длина не может превышать алфавит основания
  (в двоичной доступна только длина 2).
- Живая фильтрация ввода: недопустимые для основания символы не попадают
  в поле, hex-цифры `A–F` принимаются в обоих регистрах.
- История попыток с числом быков и коров; повторная попытка не дублируется.
- Таймер раунда и подсчёт попыток.
- Таблица рекордов в `localStorage`: топ-10 результатов на каждую
  комбинацию «основание · длина», сортировка по попыткам, затем по времени.
- «Новая игра» возвращает к настройкам без перезагрузки страницы.

## Запуск

```bash
npm install
npm run build     # компиляция TypeScript в dist/ (ES-модули)
```

Затем открыть `index.html` в браузере (страница подключает
`dist/main.js` как `<script type="module">`).

## Скрипты

| Команда                | Действие                                |
| ---------------------- | --------------------------------------- |
| `npm run build`        | компиляция `src/` в `dist/` через `tsc` |
| `npm run typecheck`    | проверка типов без эмита                |
| `npm run lint`         | ESLint по всему проекту                 |
| `npm run format`       | Prettier с перезаписью файлов           |
| `npm run format:check` | проверка форматирования без изменений   |
| `npm test`             | прогон тестов Vitest (один раз)         |
| `npm run test:watch`   | Vitest в режиме наблюдения              |

## Структура проекта

```
src/
├── game/   # чистое ядро: типы, валидация, оценка, генерация, состояние
├── ui/     # DOM-слой: экраны настроек, игры, победы и рекордов
├── utils/  # самописная мемоизация
└── main.ts # контроллер: владелец ссылки на состояние и перерисовка
tests/      # юнит-тесты ядра (Vitest, без DOM)
```

Подробное описание архитектуры, алгоритмов и их сложности — в
[DESIGN.md](./DESIGN.md).

## Тестирование

Ядро покрыто юнит-тестами (Vitest). Случайность инъецируется параметром,
поэтому генерация секрета детерминируема в тестах; мемоизация проверяется
счётчиком вызовов внутренней функции.

## Инструменты

- TypeScript (strict mode, ES-модули, компиляция через `tsc`).
- ESLint + Prettier; Husky: `pre-commit` — lint-staged,
  `pre-push` — прогон тестов.
